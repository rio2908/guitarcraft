# ГитарКрафт для Android

Игра для первых шагов на гитаре. Показывает струну и лад, проигрывает ноту, фрагмент или всю мелодию и проверяет одну сыгранную ноту через микрофон. Ритм не проверяется.

Приложение написано на Python и pygame. Исходники Android-версии не содержат игрового кода на Java или JavaScript. [Веб-версия](https://guitarcraft-notes.webpms-ai-1.chatgpt.site/) остаётся отдельной демонстрацией.

## Как играть

Нажмите **Мелодии** и выберите песню. На экране показаны номер струны и лад; струна 1 — самая тонкая. Число в круге показывает лад, который надо зажать. Пустой круг означает открытую струну. Слог под шагом помогает следить за мелодией.

Кнопки **Звук**, **Фрагмент** и **Вся песня** дают послушать пример. Сыграйте текущую ноту и нажмите **Проверить** — приложение сравнит высоту звука через микрофон. **Следующий** переключает шаг, а стрелки на грифе переключают фрагмент. Ритм не проверяется. Та же короткая инструкция открывается кнопкой **?** внутри игры.

Оформление использует собственные пиксельные блоки, деревянный гриф и цвета травы и камня; сторонние игровые текстуры и логотипы не используются.

## Запуск на компьютере

Установите `pygame` и выполните:

```powershell
python main.py
```

На компьютере можно проверить экран и прослушивание; проверка микрофона работает в Android-приложении.

## Сборка Android

В GitHub Actions откройте **Build Android Debug APK → Run workflow**. После успешной сборки скачайте артефакт **GuitarCraft-Android-debug**.

Сборка также устанавливает APK в Android-эмулятор и проверяет, что игра остаётся открытой после запуска. Версия 0.5 исправляет закрытие при первом событии Android: pygame в APK старее, чем версия на компьютере. APK дополнительно подписывается сохранённым debug-ключом. Установка на Redmi Note 7 и работа микрофона проверяются отдельно на телефоне.

Локальная сборка выполняется через Buildozer на Linux или macOS (на Windows — через WSL):

```bash
python -m pip install -r requirements-android.txt
buildozer android debug
```

Идентификатор приложения: `org.game.guitarcraft`. Минимальная версия Android: API 24. При первой проверке звука приложение запросит доступ к микрофону. Прогресс сохраняется в данных приложения. Прогресс из прежней версии с WebView автоматически не переносится.

Мелодии и позиции лежат в [`songs.json`](songs.json). Происхождение записей гитарных звуков описано в [`assets/samples/SOURCE.md`](assets/samples/SOURCE.md).
