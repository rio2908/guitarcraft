# ГитарКрафт

Игра для первых шагов на гитаре: выбери мелодию, посмотри струну и лад, послушай звук и проверь одну сыгранную ноту через микрофон. Мелодии разбиты на короткие фрагменты; ритм не проверяется.

[Открыть веб-версию](https://guitarcraft-notes.webpms-ai-1.chatgpt.site/)

## Локальный запуск веб-версии

```powershell
python -m http.server 8000 --directory dist
```

Затем открой `http://localhost:8000/`. При проверке звука браузер запросит доступ к микрофону.

## Android

Android-приложение находится в [`android/`](android/README.md). Оно включает файлы веб-версии в APK и запрашивает доступ к микрофону при проверке звука. В [GitHub Actions](.github/workflows/android.yml) предусмотрена ручная сборка debug APK.

Записи гитарных звуков и их происхождение описаны в [`dist/samples/SOURCE.md`](dist/samples/SOURCE.md).
